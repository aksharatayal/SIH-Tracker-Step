# SIH-Tracker - Smart India Hackathon Project Tracker

A Java-based tracker to organize SIH problem statements, team ideas and progress - built to show project management skills for Google STEP.

### 💡 Problem It Solves
Students participating in SIH struggle to organize 100+ problem statements. This tracker helps filter by domain and track idea status.

### ✨ Features
- Add Problem Statement ID, Title, Domain
- Track Status: Thinking / In-Progress / Final
- Filter by Domain (AI, Blockchain, Healthcare etc.)

### 🛠️ Tech Stack
Java, OOPs, ArrayList & HashMap

### 🚀 How to Run
1. Clone repo
2. Open in VS Code / IntelliJ
3. Run Main.java
